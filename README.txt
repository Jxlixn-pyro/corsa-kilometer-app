Corsa Kilometer-Manager – Installation

Diese Dateien sind eine kleine Progressive Web App (PWA).
Für die Installation auf dem iPhone muss sie unter einer HTTPS-Adresse erreichbar sein.

Einfacher Weg mit GitHub Pages:
1. Bei github.com anmelden und ein neues öffentliches Repository anlegen.
2. Alle Dateien aus diesem ZIP in das Repository hochladen.
3. Unter Settings > Pages die Veröffentlichung aus dem Branch main / root aktivieren.
4. Die angezeigte HTTPS-Adresse auf dem iPhone in Safari öffnen.
5. Teilen-Symbol > Zum Home-Bildschirm > Hinzufügen.

Hinweis: Daten werden lokal im Browser auf dem Gerät gespeichert. Nicht automatisch GPS-Tracking.
Der Startwert für November 2026 ist auf 580 km gesetzt; ab dem Folgemonat startet das Monatsbudget mit 0 km Startwert. Limit und Startwert lassen sich in der App ändern.
